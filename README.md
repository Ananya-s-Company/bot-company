# Ananya Mohata Bot Company

Codebase for the Ananya Mohata bot company, a lean side business run by AI bots.

## How work gets done

- Coding is done by **DevBot** through Claude Code, run headless in WSL Ubuntu at `~/bot-company`.
- The repo is viewed and reviewed in VS Code.
- Each run handles one story or fix.
- Changes are reviewed via `git diff` before anything is committed.
- Nothing is pushed or deployed without Ananya's approval.

## Folder layout

```
docs/    Notes, plans, and decisions
src/     Application source code
tests/   Automated tests
```
