# CLAUDE.md

Project conventions for Claude Code in this repo.

- Make small, focused changes. Work on one story or fix at a time.
- Write or update tests for any new behavior. Keep tests in `tests/`.
- Never commit secrets, keys, or `.env` files.
- Use conventional commit messages (e.g. `feat: ...`, `fix: ...`, `docs: ...`).
- Do not add git remotes, push, or deploy. Ananya approves any push or deploy.
- Keep documentation in `docs/`.
